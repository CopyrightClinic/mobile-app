# Claude Code Instructions

## Response Style
- Be concise. No explanations unless I ask for them.
- Do not summarize what you just did after completing a task.
- Do not add "I've completed the task" or similar closing statements.
- Skip preamble. Start the response with the actual answer or code.
- Don't suggest stylistic or architectural improvements unrelated to the task. Do flag bugs, security issues, or breaking changes you notice while working, briefly.

## Code Output
- Only show the changed code, not the entire file.
- Do not repeat code I just wrote back to me.
- Skip comments that explain obvious code behavior.
- Do not add docstrings unless explicitly asked.
- If you're not confident a change is correct, say so briefly rather than presenting it as done.
